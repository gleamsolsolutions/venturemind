# Validation Experiment Playbook

For every key assumption, design the cheapest test capable of disproving it.

| Test | Typical question |
|---|---|
| Customer interview | Is the problem real, frequent and painful? |
| Search/keyword test | Are people actively looking for solutions? |
| Landing page | Does the value proposition earn qualified interest? |
| Waitlist | Will a target segment take a next step? |
| Clickable prototype | Can users understand and complete the core workflow? |
| Concierge test | Can the outcome be delivered manually before automation? |
| Paid pilot | Will a buyer commit money? |
| Pricing test | Which price/packaging has credible purchase intent? |
| MVP cohort | Do users activate and return? |
| Referral test | Is there a natural reason to invite others? |

Every experiment must state:
- Hypothesis.
- Target segment and recruitment method.
- Method and sample-size rationale.
- Budget and duration.
- Primary metric and guardrails.
- Success threshold.
- Failure threshold.
- Confounders and limitations.
- Decision triggered by each outcome.

Do not invent universal conversion benchmarks. Use comparable evidence where available or label thresholds as proposed decision rules. Predefine thresholds before observing results to reduce motivated interpretation.
