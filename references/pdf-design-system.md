# VentureMind PDF Design System

## Visual direction
Modern editorial / strategy consulting report. Prefer a restrained palette: warm white background, charcoal text, one deep blue/teal or muted accent, and light neutral table fills. Avoid loud gradients, decorative clutter and excessive cards.

## Typography and layout
- A4 portrait by default; landscape only for wide competitor matrices or data appendices.
- Clear title hierarchy, generous margins and consistent spacing.
- Body text should remain comfortably readable (typically 10–11 pt in PDF).
- Use consistent heading styles, table headers, footnotes, captions and page numbers.
- Use running header with short report title and footer with date/page number.
- Use accessible contrast and meaningful chart labels.
- Keep tables together where possible; repeat table headers across pages.
- Do not split a short row across pages. Avoid orphan headings and widowed lines.
- Use hyperlinks for sources and table-of-contents entries.

## Cover
Include report title, subtitle, prepared date, research scope/geography and a restrained visual motif. Do not invent a client, company, author credential or logo.

## Charts
Only create charts from actual cited data or clearly labelled model scenarios. Include units, geography, period, source and caveats. Avoid decorative charts with no analytical purpose. Never fabricate chart values to fill a layout.

## Source handling
Number sources in order of first use or use concise inline citations with a linked bibliography. Each important finding must map to a source. Include access date for live pages. Preserve original URLs.

## Quality assurance
Render every page to images and inspect:
- clipping, overflow, overlap and cut-off text;
- unreadable font size and contrast;
- broken links and TOC links;
- blank or near-empty pages;
- inconsistent margins and typography;
- broken tables, chart labels and footnotes;
- missing citations or bibliography entries.
Fix and regenerate until clean. If the runtime cannot render or inspect the PDF, disclose that limitation rather than claiming visual QA.
